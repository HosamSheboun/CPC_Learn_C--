# Project 16: Four-element array

## Overview

Reads four array elements, reports each entry as it is recorded, then prints the array.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter four integer elements.
