# Project 23 (P-B): Replacement

## Overview

Reads an array and replaces each positive value with `1` and each negative value with `2`. Zero values remain unchanged. The resulting array is printed with values separated by spaces.

## Progress

Implementation is complete. The example input and output from the exercise are documented below; automated tests are not included.

## Example

Input:

```text
5
1 -2 0 3 4
```

Output:

```text
1 2 0 1 1
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N followed by N integers.
