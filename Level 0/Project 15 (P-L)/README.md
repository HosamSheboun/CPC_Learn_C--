# Project 15 (P-L): Lucky numbers

## Overview

Reads the inclusive range [L, R] and prints numbers whose digits are all 4 or 7. Prints -1 when none are found.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter L and R.
