# Project 22 (P-A): Linear search

## Overview

Reads an array and a target value, then prints the target's first zero-based index, or -1 if it is absent.

This is the former Project 19 (P-A). It was moved to Project 22, and the former Projects 20–22 were shifted to Projects 19–21.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N, N array elements, and the target value.
