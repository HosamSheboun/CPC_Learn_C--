# Project 6 (P-C): Sort three values

## Overview

Reads three values, prints them in ascending order, and then prints them in their original order.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter three values.
