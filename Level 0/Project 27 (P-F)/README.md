# Project 27 (P-F): Create a new string

## Overview

Reads two strings and prints their lengths on the first line, followed by both strings separated by a space on the second line.

## Progress

Implementation is complete. Both examples from the exercise were verified; automated tests are not included.

## Examples

Input:

```text
LEVEL
ONE
```

Output:

```text
5 3
LEVEL ONE
```

Input:

```text
Programming
contest
```

Output:

```text
11 7
Programming contest
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter the two strings on separate lines.
