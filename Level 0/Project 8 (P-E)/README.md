# Project 8 (P-E): Integer and fractional parts

## Overview

Reads a decimal number and reports whether it is an integer or a floating-point value, along with its integer and fractional parts.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one number.
