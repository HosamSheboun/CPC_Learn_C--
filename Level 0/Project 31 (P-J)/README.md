# Project 31 (P-J): Conversion

## Overview

Reads a line, replaces each comma with a space, and changes each English letter to the opposite case.

## Progress

Implementation is complete. The example from the exercise was verified; automated tests are not included.

## Example

Input:

```text
happy,NewYear,enjoy
```

Output:

```text
HAPPY nEWyEAR ENJOY
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one line of text.
