# Project 29 (P-H): I Love strings

## Overview

For each test case, reads two strings and interleaves their characters in order: first character from the first string, first from the second, then their second characters, and so on. If the strings have different lengths, the remaining characters are appended.

## Progress

Implementation is complete. The example from the exercise was verified; automated tests are not included.

## Example

Input:

```text
2
SECuc TMBplb
ey gpt
```

Output:

```text
STEMCBupclb
egypt
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter the number of test cases, followed by two strings for each case.
