# Project 4 (P-A): Basic data types

## Overview

Reads an integer, a large integer, a character, and a decimal value, then prints each value on its own line.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter the four values in that order.
