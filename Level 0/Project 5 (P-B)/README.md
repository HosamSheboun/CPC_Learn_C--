# Project 5 (P-B): Arithmetic operations

## Overview

Reads two values and displays their sum, product, and difference.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter two values.
