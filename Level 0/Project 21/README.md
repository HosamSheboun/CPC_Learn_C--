# Project 21: Switch statement

## Overview

Reads an integer and uses a `switch` statement to distinguish 5, 10, and all other values.

This is the former Project 22. The project was renumbered when the projects 19–22 were reordered.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one integer.
