# Project 24 (P-C): Lowest number

## Overview

Reads an array and prints its smallest value and its 1-based position. If the smallest value appears more than once, the first position is reported.

## Progress

Implementation is complete. Both examples from the exercise were verified; automated tests are not included.

## Examples

Input:

```text
3
1 2 3
```

Output:

```text
1 1
```

Input:

```text
5
5 6 2 3 2
```

Output:

```text
2 3
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N followed by N integers.
