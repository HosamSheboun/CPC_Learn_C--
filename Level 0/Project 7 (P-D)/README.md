# Project 7 (P-D): Circle area

## Overview

Reads a circle's radius and calculates its area, printed to nine decimal places.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter the radius.
