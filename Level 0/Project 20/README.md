# Project 20: Array palindrome

## Overview

Reads an array and compares matching elements from its two ends to determine whether it is a palindrome. Prints the comparison progress and a YES/NO result.

This is the former Project 21. The project was renumbered when the projects 19–22 were reordered.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N followed by N array elements.
