# Project 10 (P-G): Character classification

## Overview

Reads one character and identifies it as a digit, uppercase letter, or lowercase letter.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one character.
