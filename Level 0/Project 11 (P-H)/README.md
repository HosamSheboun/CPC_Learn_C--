# Project 11 (P-H): Count to N

## Overview

Reads an integer N and prints every integer from 1 through N, one per line.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N.
