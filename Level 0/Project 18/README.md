# Project 18: Echo array values

## Overview

Reads an array size and that many integers, then immediately prints each value as it is read.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter the array size followed by its elements.
