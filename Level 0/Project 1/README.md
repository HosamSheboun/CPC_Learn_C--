# Project 1: Transport choice

## Overview

Reads an amount of money and prints a travel option based on the available amount: tuk-tuk for 20 or more, bus for 10 or more, otherwise walking.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one integer amount.
