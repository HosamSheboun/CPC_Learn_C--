# Project 30 (P-I): Count

## Overview

Reads a string of decimal digits and prints the sum of its digits.

## Progress

Implementation is complete. The example from the exercise was verified; automated tests are not included.

## Example

Input:

```text
351
```

Output:

```text
9
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter one line containing only digits.
