# Project 26 (P-E): Palindrome array

## Overview

Reads an array and prints `YES` if its values read the same forward and backward, or `NO` otherwise.

## Progress

Implementation is complete. Both examples from the exercise were verified; automated tests are not included.

## Examples

Input:

```text
5
1 3 2 3 1
```

Output:

```text
YES
```

Input:

```text
4
1 2 3 4
```

Output:

```text
NO
```

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N followed by N integers.
