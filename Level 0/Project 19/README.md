# Project 19: Linear search walkthrough

## Overview

Reads an array and a target value, then prints a trace of a linear search and the target's first zero-based index, or -1 if it is absent.

This is the former Project 20. The project was renumbered when the projects 19–22 were reordered.

## Progress

Implementation is present and passed a g++ C++17 syntax check. Runtime behavior is not covered by automated tests.

## Build and run

From this folder, build with `g++ -std=gnu++17 main.cpp -o main.exe` and run with `.\main.exe`. Enter N, N array elements, and the target value.
